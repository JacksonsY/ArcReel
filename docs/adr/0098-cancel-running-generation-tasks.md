# 允许终止运行中的生成任务

二开版本允许用户和创作 Agent 终止长时间运行的生成任务，替代 ADR 0006 的排队限制。取消表示放弃本地执行，不承诺供应商取消或退费；界面确认与工具说明必须说明这项限制。

- 单任务和批次取消均支持 `queued/running → cancelled`，保留 `cancelled_by='user'`。级联仍只取消排队中的依赖任务。终态任务保持原状态，重复取消安全。
- 不恢复 `cancelling` 中间态，不引入取消回执或回滚已完成产物。成功与失败的 guarded UPDATE 不覆盖取消终态。
- 支持的部署仍为单个 uvicorn 进程。队列提交取消后，通过现有项目认领找到执行协程并取消；常规执行与视频续跑共用这条链路。进入执行前读取任务状态，覆盖认领后、执行前的取消窗口。
- 取消标记保留在认领对象上，随 ContextVar 传入线程。任务协程退出后，迟到的线程仍不得开启项目写入。已开始的原子事务按 `run_sync_transaction` 收尾，已完成产物保留；清理临时视频文件允许访问取消任务的项目，但仍检查项目是否被删除。
- 用量面板的单任务取消支持运行中任务；「取消所有排队任务」仍只清排队任务。Agent 可通过 `list_generation_tasks` 找到当前项目、当前用户的任务，以 `cancel_generation_task` 取消单个任务，也可用 `cancel_generation_batch` 取消整批。
- 服务正常关闭仍等待在跑任务结束。进程级打断使用 `interrupted` 来源，不覆盖已经落库的用户取消；取消任务不会在重启后重新提交。

保留排队限制能减少丢弃付费结果，但无法释放用户明确要停止的本地执行。引入回滚回执会扩大每条产物路径的维护成本；本方案保留已完成结果，只中止尚未完成的工作。供应商远端取消沿用各 backend 的现有能力，例如 ComfyUI 的尽力取消，不增加通用退费协议。
